- **[@sl4dk1y](https://github.com/sl4dk1y)** координирует работу команды, отвечает за архитектуру, LLM-оркестрацию, общий Consultant Engine, интеграцию компонентов, конкурсный runtime и code review.

- **[@pesocheck](https://github.com/pesocheck)** отвечает за интерфейс чата, отображение истории, формы заявок, UI-состояния и взаимодействие с backend API.

## Совместная ответственность за Backend

- **[@sl4dk1y](https://github.com/sl4dk1y)** отвечает за архитектуру backend, интеграцию с Consultant Engine и согласование API-контрактов.
- **[@kodi842](https://github.com/kodi842)** отвечает за реализацию backend API, управление сессиями, заявки и связанную серверную логику.

Это распределение помогает координировать работу; участники могут вместе менять любые компоненты.

## Командная работа и безопасность

Каждый работает в своей ветке и предлагает изменения в `main` через Pull Request. Общие API и контракты предварительно согласуют их ответственные. По возможности изменения проверяет другой участник. Тимлид координирует интеграцию, а реализацию распределяет команда.

Процесс разработки описан в [CONTRIBUTING.md](CONTRIBUTING.md), требования безопасности — в [SECURITY.md](SECURITY.md).

## CODEOWNERS

В `.github/CODEOWNERS` указаны участники, которых GitHub просит проверить изменения в закреплённых областях. Эти правила не мешают другим участникам работать с файлами. Обязательное одобрение и защиту ветки настраивают отдельно в GitHub.

## Лицензия
